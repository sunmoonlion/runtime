## 已实现

| 条件 | 实现与验证 |
| --- | --- |
| 零电脑首次进入首页 | 首页顶部卡片与「接入电脑」；登记电脑后从只读查询中移除卡片 |
| 工作、专家无电脑 | 首页两种模式、专家列表页、指定项目请专家页直接指向同一接入页 |
| 新建项目没有电脑/目录 | 列表空态与新建窗口有接入链接；不再因无工作区而连窗口都打不开；创建本身仍须有电脑与白名单目录 |
| 侧栏状态 | 「我的电脑」下显示可点击的在线/离线/未登记状态；查询失败不误报未登记 |
| 命名 | 中英文分别为「我的电脑 / My computers」「接入电脑 / Connect computer」；内部 API 字段和 `/machines` 路径不改 |
| 五步 | 下载 → 校验安装 → 领取令牌 → 选目录 → 在线；面板、锚点与顺序一致，初始化命令仍在令牌面板 |
| 无隐式写入 | 接入链接只导航；页面加载、刷新、勾选进度均不签发、轮换令牌，不创建项目，不替本机授予权限 |

**首页与聊天的区分：** `/workbench` 保留首次欢迎卡；显式「聊天」和侧栏「新建聊天」
使用已有的 `?mode=chat` 参数，不显示接电脑卡片。项目聊天本来也带该参数。
聊天仍只按云端沙箱条件启动，不受电脑登记/在线与否阻拦；聊天正文页未改。
全局侧栏保留「我的电脑」导航及状态，移除了原来在侧栏工作区空态中反复提示安装代理的文案。

**进度的证据范围：**

- 下载、安装由用户自己勾选，仅保存在当前页面内存；不把下载点击或进页面算成功。
- 令牌一步根据已有身份签发记录打勾，不代表已经复制、也不代表本机初始化成功；页面写明此区别。
- 目录来自电脑上报；最后一步要求**同一台已选目录的电脑在线**，不能把离线电脑的目录与另一台空目录电脑拼起来。
- 首页与接入页每 5 秒刷新电脑查询；查询未完成/失败时不报告「没有电脑」或「在线通过」。
- 这些是引导状态，不是安全授权或发行验收。本机目录授权、令牌期限与真实安装验收仍各自生效。
