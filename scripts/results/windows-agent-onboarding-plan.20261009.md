# Windows 代理安装与首次接入改造方案

> 状态：方案待 Fable 审读和所有者确认；本文件只定方案，不代表已实现或验收。
> 基线：真实下载、PowerShell 解压、手工领令牌后已连通；开发 CA 信任和首次安装体验未达目标。

## 目标流程

用户先在「设置」登记模型 key，再进入「设置 → 我的电脑」下载 ZIP。解压后双击「安装」，安装器校验包并打开设置窗口；用户点「连接我的账号」，本机显示一次性配对码并打开浏览器确认页。登录用户确认后，代理在本机取得自己的令牌；用户选择目录、确认开机自启（默认开启，可关闭），完成。安装与接入不要求打开终端、复制令牌或手工设置环境变量。

默认普通用户权限、Windows unelevated 沙箱和禁网上限不变；管理员沙箱仍是用户主动选择的可选项。多台电脑同时在线仍属第二期。

## 方案

| 范围 | 实施设计与边界 |
| --- | --- |
| 双击入口先实测 | 从浏览器下载带 Mark-of-the-Web 的真实 ZIP，经资源管理器解压；在应用控制保持开启、执行策略不变的机器上，分别双击 `.cmd`、`.ps1`、`.vbs`、`.lnk`（指向官方签名 `node.exe`）并记录 SmartScreen、SAC/WDAC 和策略的实际提示。不得关闭应用控制或修改执行策略。实测决定是否需要重新评估代码签名证书；未测前不采购、不声称双击可用。 |
| 浏览器确认配对 | 提前实现原第二期配对：代理创建短时、一次性请求，展示短码并轮询；网页登录后展示待连接机器信息，用户确认或取消。建议有效期 5 分钟，短码尝试限速。短码只用于找到待确认请求，不是令牌；代理另持高熵配对秘密，服务端只存其摘要。确认绑定登录用户和该请求，令牌只通过该代理的 TLS 轮询通道交付，不返回浏览器、不进 URL/日志/浏览器存储。过期、取消、重放、错用户、限速命中均拒绝并审计。复用现有签发、30 天期限及身份轮换逻辑，不新建令牌体系；网页现有手动领令牌保留为备用。新配对若会替换该用户当前代理，确认页必须先说明并要求明确确认。 |
| TLS 与错误提示 | 所有随包 Node 启动入口（安装器、CLI、托盘、登录任务和后台）显式启用系统证书库，不能依赖被清理掉的 `NODE_OPTIONS`。开发环境显示待信任 CA 的指纹，并从已认证的「我的电脑」页面核对指纹后，由用户明确同意导入当前用户的受信任根；不需管理员。正式环境用受信任公共证书，不提示导入。错误保留 TLS 错误码并转成可执行的人话（例如“开发证书未受信任，请核对指纹并导入”）；日志、状态和托盘不包含令牌。不得关闭 TLS 校验。 |
| 包校验 | 安装器在执行包内程序前校验 ZIP 摘要与清单文件摘要；预期摘要来自登录后的可信发布元数据，并显示版本、大小和校验值。清单用于发现损坏，不能单独证明发布者身份。保留手工校验方式；校验不符即停止，不解压执行。 |
| 首次设置与入口 | 设置窗口按「连接账号 → 选择目录 → 开机自启（默认开）→ 完成」顺序呈现；每步支持返回、取消和重试，并解释账户未配置、配对过期、网络/TLS、目录权限、包校验失败等下一步。现有「我的电脑」内容移入「设置 → 我的电脑」；侧栏只留在线状态点并链接到该设置节，首页/工作/专家/新建项目的接入提示统一跳转到同一处。 |

## 跨仓交付与停点

1. **实验卡**：完成真实 ZIP 来源标记与双击入口矩阵，提交原始提示、Windows 应用控制状态和结论；若被策略拦截，再提出签名证书决策，不绕过系统策略。
2. **配对后端卡**：设计并实现一次性请求、所有者确认、代理专属轮询交付、取消/过期/重放/限速及审计；仅复用现有 30 天令牌签发器。覆盖并发、错误身份、CSRF、过期、重放和取消竞态。
3. **网页与代理卡**：网页把「我的电脑」并入设置并提供确认页；runtime 增加安装设置向导、系统 CA 支持、令牌接收和安全存储、易懂错误及开机自启设置。前后端配对契约一起审，手动领令牌继续可用。
4. **发行验收卡**：固定源码与版本，重新组 ZIP，上传前后校验；从浏览器下载开始，由所有者只用鼠标走完安装、指纹核对、配对、选目录、自启、网页在线。之后单独验重启自启、托盘关闭与停止、取消/过期配对和干净 Windows 安装。真人尚未执行的项目保持待验，不用自动化测试替代。

代码范围涉及 `investment-backend`、`investment-web-frontend`、`runtime`；如需改发布锁、GitOps 或构建/上传卡，再在 `k8s` 增加对应发布提交。各仓先分别提交并审读，按现有成对发布与固定包流程晋级；发布前停止交所有者安排，不从旧源码或未审版本组包。

## 当前事实与未决风险

- 代理令牌已按既定决定采用 30 天；本方案不再提出 24 小时期限，也不改其他令牌期限。
- 目前每个用户仅允许一个活动代理，新配对可能替换现有连接；多设备并行明确延期。
- 本机真人使用浏览器下载和 PowerShell 解压后成功连通；资源管理器双击、打包版首次配对、开机自启及干净 Windows 均未验收。
- 开发 CA 指纹必须通过可信页面核对后再导入；若安装包与网站都无法提供可信指纹，先解决信任引导，不允许让安装器盲目信任包内 CA。
- 当前不改代码、不构建、不发布、不操作集群。待 Fable 审读和所有者确认后，按上述卡片推进。
